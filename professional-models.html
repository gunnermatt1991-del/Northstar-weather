Data and attribution

Built on recognised forecast sources

  • GFS data: NOAA / NCEP NOMADS.
  • ECMWF Open Data: CC BY 4.0 and ECMWF terms; required attribution will appear with charts.
  • UKMO: Weather DataHub licence, API plan and “Powered by Met Office data” attribution must be applied.

Model output is guidance, not an official warning. Model runs can change, arrive late or be revised. Northstar will display the source, model cycle, issue time and forecast valid time on every chart.
